Política de privacidad

Vigente desde el 29 de septiembre de 2026

Qué datos se usan

Al autorizar la herramienta, TikTok le entrega un identificador de la cuenta (open_id) y un token de acceso con el permiso video.upload. Solo se usan para subir los videos que el propio dueño elige.

Dónde se guardan

El token y el identificador se guardan únicamente en el computador del dueño de la cuenta. No se envían a ningún servidor propio, no se venden y no se comparten con nadie.

Qué no se hace

  • No se leen mensajes, seguidores, estadísticas ni otros datos de la cuenta.
  • No se recopilan datos de otras personas.
  • No se usan cookies ni herramientas de seguimiento en estas páginas.

Cómo retirar el permiso

En la app de TikTok: Configuración y privacidad → Seguridad → Aplicaciones y servicios → quitar el acceso. Al hacerlo, el token deja de funcionar.

Contacto

Mediante el repositorio del proyecto en GitHub.
